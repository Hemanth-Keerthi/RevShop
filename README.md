# RevShop - Console Based E-Commerce Application

## Overview

RevShop is a Java console-based e-commerce application built using JDBC
and Oracle Database. It follows layered architecture (Controller →
Service → DAO → Database).

## Features

### Buyer

-   View Products
-   Cart & Checkout
-   Payment
-   Order History + Invoice
-   Wishlist
-   Reviews
-   Notifications

### Seller

-   Add Products
-   View Own Products
-   View Sales Summary

## Tech Stack

-   Java (OOP)
-   JDBC
-   Oracle XE
-   IntelliJ IDEA
-   GitHub

## Database Setup

Run `/database/RevShop_Phase1_Oracle.sql` in Oracle SQL Developer.
